epoll - Wikipedia

en.wikipedia.org/wiki/Epoll
epoll is a Linux kernel system call for a scalable I/O event notification mechanism, first introduced in version 2.5.45 of the Linux kernel in October, 2002. [1][2] Its function is to monitor multiple file descriptors to see whether I/O is possible on any of them.
